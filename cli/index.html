CookCLI

Your recipe folder, from the terminal. Shopping lists, a local web server, search, reports and a static website — all from plain .cook files, the UNIX way.

$ brew install cookcli

Or grab a binary, RPM or cargo install — see all install options.

cook server

Your recipes in the browser

One command turns your folder into a web app on your network: browse and search, scale recipes, build a shopping list, plan with menus and keep a pantry.

localhost:9080/recipe/Neapolitan Pizza
$ cook server ~/recipes --host
Try the live demo Server docs →

Building an integration? The server exposes an HTTP API. Want it always on? Run it on a Raspberry Pi.

Small tools that compose

Shopping lists

$ cook sl "Weekly Plan.menu"

Combine recipes or a whole menu into one list, grouped by aisle, minus what's in your pantry.

Search

$ cook search chicken

Find recipes by any word in them: an ingredient, a step or a title.

Import

$ cook import <url>

Turn a recipe from a website into a clean .cook file.

Static website

$ cook build web

Publish your collection as a searchable static site for GitHub Pages or Netlify.

Reports

$ cook report -t cost.md.jinja

Render any recipe or menu through a template: costs, nutrition, printable cards.

Pantry

$ cook pantry expiring

See what's running low or about to expire, and what you can cook with what you have.

Doctor

$ cook doctor

Check recipes for errors, and spot ingredients missing from your aisle and pantry files.

Editor support

$ cook lsp

A language server for completion and diagnostics in VS Code, Neovim and other editors.

Sync#

cook login signs CookCLI in to Cook Cloud sync (Cook Basic). While cook server runs, it keeps your recipe folder in step with the Cook mobile apps and Cook Editor. cook logout signs out.
