CookCLI

Your recipe folder, from the terminal. Shopping lists, a local web server, search, reports and a static website — all from plain .cook files, the UNIX way.

$ brew install cookcli

Or grab a binary, RPM or cargo install — see all install options.

cook server

Your recipes in the browser

One command turns your folder into a web app on your network: browse and search, scale recipes, build a shopping list, plan with menus and keep a pantry.

localhost:9080/recipe/Neapolitan Pizza
$ cook server ~/recipes --host
Try the live demo Server docs →

Building an integration? The server exposes an HTTP API. Want it always on? Run it on a Raspberry Pi.
